01 / CONTROL LOOP

Use semantics until pixels are the better answer.

FastCUA routes every action through fresh window state. Good accessibility data stays fast and precise. Weak or stale semantics switch to a numbered visual grid with repeatable refinement.

A

Read the interface

Inspect UI Automation names, roles, bounds, focus, and quality before spending a vision turn.

get_window_state()
B

Refine the image

When semantics are weak, select a numbered square and refine it into a new 3×3 view until the target is isolated.

grid_refine()
C

Commit one action

Click exactly once against the current capture, then re-observe whenever focus or layout may have changed.

click_cell()

03 / SKILL RECORDER · PREVIEW

Turn a demonstration into evidence an agent can audit.

The optional recorder captures an interaction, compiles an evidence package, and lets the current primary agent write a reusable Skill. Provenance lint, a dry run with new values, and human-reviewed promotion remain hard gates.

Read the recorder playbook ↗

  2. 02CompileEvidence package
  3. 03AuthorPrimary agent

Using the Skill Recorder may send recorded screen content, interaction evidence, and narration to the configured cloud model provider.
